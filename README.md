# Career Fit Radar AI Skill

> 사용자의 프로필과 채용공고를 비교해  
> 지원 적합도와 부족한 조건을 빠르게 확인할 수 있도록 돕는 AI Skill

**MABC Challenge 2026 출품작**  
주관: 업스테이지

---

## 📌 Project Overview

취업을 준비하는 대학생, 졸업예정자, 신입 구직자는 여러 채용공고를 확인하면서  
각 공고의 **지원자격과 우대사항을 자신의 조건과 반복해서 비교**해야 합니다.

하지만 공고마다 작성 방식이 다르고 정보량도 많아,

- 내가 필수조건을 충족하는지
- 어떤 우대조건을 가지고 있는지
- 부족한 조건은 무엇인지
- 실제로 지원해볼 만한 공고인지

를 매번 직접 확인해야 하는 번거로움이 있습니다.

**Career Fit Radar AI Skill**은 사용자의 프로필과 채용공고를 분석하여  
공고의 조건을 구조화하고, 사용자의 조건과 하나씩 비교해  
지원 적합도를 직관적으로 보여주는 AI Skill입니다.

---

# 💡 Problem

취업 준비 과정에서 채용공고를 찾는 것만큼 어려운 것이  
**“이 공고가 나에게 적합한가?”를 판단하는 과정**입니다.

사용자는 채용공고를 읽은 뒤 다시 자신의 전공, 학점, 어학점수, 자격증, 경험 등을 비교해야 합니다.

특히 여러 공고를 확인할수록 같은 정보를 반복해서 입력하거나  
각 지원조건을 일일이 비교해야 하는 부담이 커집니다.

Career Fit Radar는 이러한 반복적인 비교 과정을 AI가 대신 수행하도록 설계했습니다.

---

# 🎯 Target User

Career Fit Radar는 다음과 같은 사용자를 대상으로 합니다.

- 취업을 준비하는 대학생
- 졸업예정자
- 신입 구직자
- 여러 채용공고 중 자신의 조건에 맞는 공고를 빠르게 판단하고 싶은 사용자

---

# 🚀 Core Idea

사용자의 프로필과 하나의 채용공고를 비교하여  
공고에 명시된 조건을 다음과 같이 분류합니다.

### 필수조건
지원하기 위해 반드시 충족해야 하는 조건

### 우대조건
필수조건은 아니지만 보유할 경우 유리한 조건

### 참고정보
직무, 근무지역, 전형절차 등 지원 판단에 필요한 부가 정보

AI는 각 조건과 사용자의 프로필을 비교한 뒤  
지원 가능 여부를 직관적으로 보여줍니다.

---

# 🚦 Fit Analysis

Career Fit Radar는 사용자의 조건과 공고를 비교하여  
지원 상태를 색상으로 표시합니다.

### 🟢 지원 가능

공고의 주요 필수조건을 충족하는 경우

### 🟡 보완 필요

지원은 가능하지만 일부 우대조건이나 역량이 부족한 경우

### 🔴 지원 어려움

공고에 명시된 필수조건을 충족하지 못한 경우

단순히 색상만 표시하는 것이 아니라  
**어떤 조건을 충족했고 어떤 조건이 부족한지 근거와 함께 설명합니다.**

---

# ⚙️ How It Works

Career Fit Radar는 다음 순서로 동작합니다.

```text
사용자 프로필 입력
        ↓
채용공고 입력
        ↓
채용공고 내용 분석
        ↓
필수조건 / 우대조건 / 참고정보 분류
        ↓
사용자 프로필과 각 조건 비교
        ↓
지원 적합도 판단
        ↓
🟢 지원 가능
🟡 보완 필요
🔴 지원 어려움
        ↓
부족한 조건 및 판단 근거 제공
